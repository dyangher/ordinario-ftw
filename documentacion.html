Este documento describe la arquitectura, tecnologías, funcionalidades y cumplimiento de los requisitos del sitio.

Estructura del sitio

El sitio consta de 5 páginas principales (más esta documentación):

  • index.html – Página de inicio con presentación del proyecto.
  • musica.html – Listado de bandas musicales con ordenamiento dinámico.
  • juegos.html – Listado de juegos favoritos con ordenamiento dinámico.
  • dyangher.html – Perfil personal y botón de contacto.
  • contacto.html – Ventana flotante con login y formulario de mensaje.
  • documentacion.html – Esta página.

Todas las páginas comparten un diseño uniforme con style.css y funcionalidad común con script.js.

Fuente de datos (XML)

El archivo datos.xml contiene dos secciones principales:

<seccion nombre="musica">
  <banda>
    <nombre>Radiohead</nombre>
    <imagen>...</imagen>
    <descripcion>...</descripcion>
  </banda>
</seccion>
<seccion nombre="juegos">
  <juego>...</juego>
</seccion>

Se cargan 12 bandas y 7 juegos.
El script script.js parsea el XML y genera tarjetas de forma dinámica.

Funcionalidades destacadas

1. Carga dinámica de datos desde XML

script.js detecta en qué página se está (música o juegos) y carga el contenido correspondiente usando fetch y DOMParser. Las tarjetas se generan con createElement y se inyectan en el DOM.

2. Ordenamiento dinámico de tarjetas

En musica.html y juegos.html hay botones (A-Z, Z-A, Aleatorio) que reordenan las tarjetas sin recargar la página. El script interno captura las tarjetas actuales, las ordena por el texto del <h3> y las vuelve a insertar.

// Ejemplo: ordenar A-Z en música document.getElementById('orden-asc').addEventListener('click', () => { let tarjetas = Array.from(grid.children); tarjetas.sort((a,b) => a.querySelector('h3').textContent.localeCompare(b.querySelector('h3').textContent)); grid.innerHTML = ''; tarjetas.forEach(card => grid.appendChild(card)); });

3. Login y envío de mensaje (ventana flotante)

La página contacto.html se abre como una ventana modal (fondo oscuro, animación) y solicita usuario USER y contraseña 1234567890. Tras autenticarse, muestra un formulario de contacto. Al enviar, se simula el éxito y se ofrece un botón para volver al inicio (index.html).

4. Diseño responsivo y estética Frutiger Aero

Se utilizan fondos degradados, efectos de cristal (backdrop-filter: blur()), bordes brillantes y tipografía clara. Las media queries ajustan el diseño para móviles.
